# Glossário

Lista de termos relevantes e definições para o projeto.

---

## Conceitos de Criação de Conteúdo

| Termo             | Definição                                                                                                                                                        |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hook**          | Os primeiros 1-3 segundos do vídeo. É o gancho que prende a atenção do espectador para evitar o scroll. Deve conter curiosidade, surpresa, conflito ou promessa. |
| **CTA**           | Call To Action. Comando ao final do vídeo que direciona o espectador a uma ação (curtir, comentar, compartilhar, inscrever-se, assistir próximo vídeo).          |
| **B-roll**        | Imagens ou vídeos secundários sobrepostos à narração principal. Serve para ilustrar o que está sendo dito e manter o dinamismo visual.                           |
| **Curiosity Gap** | Lacuna de curiosidade. Técnica onde se revela parte da informação mas retém o desfecho, forçando o espectador a assistir até o final para saciar a curiosidade.  |
| **Payoff**        | A entrega/recompensa do vídeo. O momento em que a promessa feita no hook/curiosity gap é cumprida. Se o payoff não entrega, o espectador sai frustrado.          |
| **Retenção**      | Métrica que mostra em que porcentagem do vídeo os espectadores pararam de assistir. Fundamental para entender se o conteúdo mantém interesse.                    |
| **Watch Time**    | Tempo total que os espectadores passaram assistindo seus vídeos. Métrica crucial para o algoritmo do YouTube.                                                    |
| **CTR**           | Click Through Rate. Taxa de cliques = (cliques / impressões) × 100. Mede o quão atrativo é seu título + thumbnail.                                               |

## Conceitos de Monetização

| Termo | Definição |
|---|---|
| **RPM** | Revenue Per Mille. Receita por mil visualizações. Valor estimado que você ganha a cada 1000 views. Varia por nicho, país do público e tipo de conteúdo. |
| **CPM** | Cost Per Mille. Custo por mil impressões que os anunciantes pagam. O RPM é o que chega para o criador, o CPM é o que o anunciante paga (plataforma fica com a diferença). |
| **Monetização YouTube** | Exige 1000 inscritos + 4000 horas de watch time nos últimos 12 meses OU 10M de views em Shorts em 90 dias. |
| **Monetização TikTok** | Creator Fund / Creativity Program Beta: exige 10K seguidores + 100K views nos últimos 30 dias (varia por região). |

## Conceitos Técnicos

| Termo | Definição |
|---|---|
| **MCP** | Model Context Protocol. Protocolo aberto que padroniza a comunicação entre agentes de IA e ferramentas/serviços externos. Permite que Claude/outros LLMs chamem n8n, Higgsfield, APIs, etc. |
| **SOP** | Standard Operating Procedure. Documento que descreve passo a passo como executar um processo. No Polvo, cada SOP define um fluxo operacional (ex: criar um vídeo do zero). |
| **n8n** | Plataforma de automação open source com nodes visuais. No Polvo funciona como orquestrador: conecta triggers, APIs, agentes, ferramentas em workflows automatizados. |
| **MOC** | Map of Content. Nota índice que agrupa e organiza links para outras notas relacionadas. Funciona como um "sumário" de uma seção do vault. |
| **RAG** | Retrieval Augmented Generation. Técnica onde o LLM consulta uma base de conhecimento antes de responder, em vez de depender apenas do treinamento. |
| **Agentic** | Sistema onde agentes de IA tomam decisões e executam ações de forma autônoma, não apenas respondem prompts. O Polvo 4.1 é uma arquitetura agentic. |
