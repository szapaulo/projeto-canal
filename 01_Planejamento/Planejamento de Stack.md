# 0. 🎯 A MISSÃO DO POLVO

O Polvo não é:

> "um conjunto de ferramentas de IA para fazer vídeos."

É:

> **um sistema autônomo de criação e escala de conteúdo que encontra oportunidades, entende por que elas funcionam, cria novas peças, publica, mede os resultados e utiliza os dados para melhorar o próximo ciclo.**

A unidade básica é:

**DADO → DECISÃO → PRODUÇÃO → DISTRIBUIÇÃO → FEEDBACK → APRENDIZADO**

# 32. 🔥 O QUE TORNA ISSO DIFERENTE

Existem **3 níveis**.

### Nível 1 — usuário de IA

Você pergunta:

> "Faça um roteiro."

IA responde.

---

### Nível 2 — automação

Você cria:

> workflow → gera roteiro → gera voz → gera vídeo.

Melhor.

---

### Nível 3 — POLVO 4.1

O sistema:

> **procura oportunidades → escolhe → pesquisa → desmonta → cria → critica → produz → publica → mede → aprende → modifica sua próxima decisão.**

Isso é uma arquitetura **agentic + feedback loop**.

E é exatamente onde o n8n está evoluindo: a plataforma hoje posiciona explicitamente seus recursos para workflows agentic e sistemas multiagente, enquanto o MCP permite conectar esses agentes às ferramentas externas.

Essa é a versão que faz sentido chamar de **Stack Polvo 4.1 completa**, em vez de simplesmente uma lista de ferramentas.
