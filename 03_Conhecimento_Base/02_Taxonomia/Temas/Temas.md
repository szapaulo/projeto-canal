# Temas

Lista geral de temas para escolher e desenvolver. Podemos combinar temas.

---

## Estrutura de Organização

Cada tema está organizado em:
- **Nome do tema** (ex: IA, Dota 2, Física)
- **Subtópicos** (ex: IA → Machine Learning, GPT-4, etc.)
- **Exemplos de conteúdo** (vídeos que já funcionaram)
- **Potencial de engajamento** (alto, médio, baixo)
- **Nicho associado** (qual público-alvo atende)
- **Formatos recomendados** (Ranking, Gameplay, Curiosidades, etc.)

## Como Usar

1. Escolha um tema da lista
2. Explore os subtópicos
3. Identifique o nicho associado
4. Defina o ângulo de abordagem
5. Escolha o formato de vídeo
6. Crie o hook

---

## Observações

- Temas podem ser combinados (ex: "IA + Criatividade" = "Como usar IA para criar arte")
- Temas com alto engajamento e baixa concorrência são prioritários
- A lista será atualizada com base em dados reais de performance
- Priorizar temas com alto potencial de retenção (para algoritmo do YouTube)
