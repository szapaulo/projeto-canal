# Formatos

Listar formatos mais populares e que geram mais engajamento para servir de referência. Verificar quais se encaixam melhor no modelo dark.

---

## O que é um Formato?

Um **formato** é a estrutura narrativa e visual de um vídeo. O mesmo tema pode render muitos formatos diferentes.

**Exemplo:** Tema "IA" pode render:
- Ranking (top 5 ferramentas de IA)
- Tutorial (como usar ChatGPT)
- Notícias (lançamentos da OpenAI)
- Curiosidades (o que a IA faz enquanto você dorme)

---

## Formatos Disponíveis

### Ranking
- **Descrição:** Lista de itens em ordem de mérito ou popularidade
- **Potencial de engajamento:** Alto
- **Formatos recomendados:** Shorts, Reels, TikTok
- **Combinações ideais:** Curiosidades, Tecnologia, Games
- **Status:** Ativo — recomendado para fase inicial

### Gameplay
- **Descrição:** Gravações de jogadas com comentários ou edição
- **Potencial de engajamento:** Médio-Alto
- **Formatos recomendados:** YouTube, Twitch, TikTok
- **Combinações ideais:** Games, Competitivos
- **Status:** Ativo — recomendado para nicho Games

### Tutoriais
- **Descrição:** Passo a passo para ensinar algo
- **Potencial de engajamento:** Médio
- **Formatos recomendados:** YouTube, TikTok
- **Combinações ideais:** Educação, Tecnologia
- **Status:** Ativo — bom para retenção

### DIY
- **Descrição:** Faça você mesmo, projetos práticos
- **Potencial de engajamento:** Médio
- **Formatos recomendados:** YouTube, Pinterest
- **Combinações ideais:** Criatividade, Tecnologia
- **Status:** Ativo — bom para nicho makers

### Compilações
- **Descrição:** Reunião de vários clipes ou momentos
- **Potencial de engajamento:** Alto
- **Formatos recomendados:** Shorts, Reels, TikTok
- **Combinações ideais:** Arte, Curiosidades, Games
- **Status:** Ativo — excelente para viralização

### POV
- **Descrição:** Primeira pessoa, experiência imersiva
- **Potencial de engajamento:** Médio-Alto
- **Formatos recomendados:** Shorts, Reels, TikTok
- **Combinações ideais:** Curiosidades, Saúde, Relacionamento
- **Status:** Ativo — bom para retenção

### Notícias
- **Descrição:** Atualizações rápidas sobre eventos
- **Potencial de engajamento:** Alto
- **Formatos recomendados:** Shorts, Reels, TikTok
- **Combinações ideais:** Atualidades, Tecnologia, Games
- **Status:** Ativo — bom para engajamento imediato

### Curiosidades
- **Descrição:** Fatos interessantes e surpreendentes
- **Potencial de engajamento:** Alto
- **Formatos recomendados:** Shorts, Reels, TikTok
- **Combinações ideais:** Educação, História, Ciência
- **Status:** Ativo — excelente para engajamento

## Observações

- Formatos devem ser testados e comparados com dados reais
- Priorizar formatos com alto potencial de retenção
- Ranking, Compilações e Curiosidades são os mais recomendados para modelo dark
- Gameplay é recomendado apenas para nicho Games
