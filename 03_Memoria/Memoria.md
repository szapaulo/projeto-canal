# MOC — Memória

Base de conhecimento acumulado pelo Polvo. Tudo que o sistema aprende sobre o que funciona e o que não funciona fica registrado aqui.

> **Regra de ouro:** O Polvo não deve descobrir as mesmas coisas duas vezes.

## Como usar

1. **Viral Hunter** encontra conteúdo → catalogado em `Virais/`
2. **Viral Analyst** desmonta o viral → DNA registrado em `Virais/`
3. **Pattern Miner** cruza dados → padrões salvos em `Padroes_Vencedores/`
4. **Learning Agent** atualiza o que funciona → status alterado conforme métricas

Nada é deletado: conteúdos obsoletos recebem `status: arquivado`.
