# Agente: Visual

## Função

Produtor visual. Gera e coordena todos os elementos visuais do vídeo conforme o storyboard.

---

## Responsabilidades

- Gerar imagens estáticas (Midjourney, ChatGPT Image, Canva, Photopea)
- Gerar clipes de vídeo (Kling, Sora, Higgsfield)
- Coletar/gerar B-roll
- Garantir consistência estética entre cenas

---

## Input / Output

| Direção | Descrição |
|---|---|
| **Recebe de** | [[06_Agentes/Creative Director\|Creative Director]] |
| **Input** | Storyboard |
| **Entrega para** | [[06_Agentes/Producer\|Producer]] |
| **Output** | Pasta de assets visuais organizada por cena |

---

## Ferramentas

| Ferramenta | Propósito |
|---|---|
| Midjourney | Imagens de alta qualidade |
| ChatGPT Image | Imagens rápidas |
| Kling | Geração de vídeo |
| Sora | Geração de vídeo |
| Higgsfield | Geração de vídeo + agente multimídia |
| Canva | Design rápido |
| Photopea | Manipulação de imagem |

---

## Critérios de qualidade

- [ ] Todos os assets correspondem às cenas do storyboard
- [ ] Estilo visual consistente
- [ ] Sem artefatos ou distorções visíveis
